# Craboo 网页演示

将陪伴交互、三维外观、浏览器内 MuJoCo 桌面仿真和三自由度单足结构演示整合在一个静态网页中。

## 本地运行

```sh
node server.mjs
```

打开 `http://localhost:4173/`。也可使用任何能正确提供 JavaScript 模块和 WebAssembly MIME 类型的静态服务器。

## 功能边界

- MuJoCo 在浏览器中实时计算；前进、转向采用仓库的 lifted 参考步态。按住 Ctrl 拖动可施加扰动。
- 两层上壳分别绕自己的倾斜轴旋转；电机没有接入实体硬件。
- 单足结构页的关节角度为交互示意，不模拟接地步态。
- 录音与声音存档保存在当前浏览器。实时聆听只分析音量；噪声抑制使用浏览器原生选项，效果取决于设备。
- 三维模型有缺失的源贴图，以近似材质显示。
